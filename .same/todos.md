## Instrucțiuni Deploy

### Netlify Drop (cel mai simplu)
1. Mergi la https://app.netlify.com/drop
2. Trage și lasă folderul `site-final/` pe pagină
3. Site-ul va fi live în câteva secunde

### cPanel / Shared Hosting
1. Accesează File Manager în cPanel
2. Navighează la public_html
3. Încarcă tot conținutul din `site-final/`
4. Asigură-te că index.html este în rădăcină
